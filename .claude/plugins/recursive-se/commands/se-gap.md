汇总 SE 差距，生成路线图。

## 执行步骤

1. 扫描 `docs/SE/**/P7-verification.md`，抽取全部 REQ 行的三态（PASS / FAIL / BLOCKED；PARTIAL 若有也取）。
2. 汇总为全局差距清单，按影响排序（跨 SoI 阻塞的 > 单 SoI 核心使命的 > 边缘的）。
3. 输出：

```
全局差距（截至 <日期>）
FAIL     3 条：REQ-REC2(投影重建) / REQ-E3(README) / ...
BLOCKED  1 条：REQ-G1（缺端到端实测环境）
PARTIAL  6 条：…

建议消差顺序（差距驱动，非想到什么做什么）：
1. <REQ> —— 为什么它第一（阻塞了谁/离使命多近）
2. …
```

4. 询问用户要消哪个差距；确认后可直接进入实现（实现完成后必须回 P7 补证据改状态）。

## 底线

差距清单是唯一合法的工作来源——新工作不在这张表上，先回 P2 登记 REQ（或被拒绝）。
