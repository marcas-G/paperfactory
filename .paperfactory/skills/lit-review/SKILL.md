# Literature Review Skill

## Purpose
Conduct systematic literature review on a given research topic.

## Steps
1. Search for relevant papers using `search_scholarly`
2. Parse key papers with `parse_pdf` for full-text analysis
3. Extract findings, methodologies, and gaps
4. Synthesize results into knowledge items

## Output
- Structured knowledge items with certainty levels
- Identified research gaps
- Citation network mapping
